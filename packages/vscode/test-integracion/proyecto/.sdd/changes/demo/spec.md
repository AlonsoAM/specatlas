# Delta — Cambio de prueba

## Requisitos agregados

### Requisito: REQ-DEMO-001 — Comportamiento de prueba
El equipo comprueba que la extensión arranca con un cambio en curso.

- Regla BR-DEMO-001: el cambio existe mientras dure la prueba

#### Escenario: REQ-DEMO-001-S1 — Con un cambio en curso
- **CUANDO** la instancia de prueba abre este proyecto
- **ENTONCES** la extensión activa y muestra el cambio
